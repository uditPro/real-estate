# real-estate

Premium real-estate portfolio concept built as **AUREL Estates**.

## What is included

- Editorial landing page for a curated property portfolio.
- Hero residence slider with cinematic image transitions.
- Interactive Three.js architectural villa study with day/night lighting, orbit controls, keyboard controls, and reduced-motion support.
- Responsive property collection with category filters, saved homes, gallery details, and honest portfolio-concept disclosure.
- Inquiry flow that prepares an email when `VITE_CONTACT_EMAIL` is configured, or downloads a local inquiry file when it is not.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:4173`.

## Checks

```bash
npm test
npm run typecheck
npm run build
```

## Deploy

This is a static Vite build. Run `npm run build` and deploy the generated `dist/` directory to GitHub Pages, Netlify, Vercel, or another static host.

The current property content is clearly marked as a portfolio concept and should be replaced with verified listings before public production use.
